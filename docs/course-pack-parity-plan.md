# Rounds Course-Pack Parity Plan

## Purpose

Rounds will bring every active course pack to the **same learning-system standard** as Nursing without copying Nursing’s clinical language, question wording, safety rules, or user interface. The shared standard is a learner experience: local-first access, meaningful topic depth, varied no-repeat sessions, clear feedback, adaptive revisit paths, saved work, private progress, and appropriate subject-specific assessment.

## Parity Standard

Every active non-Nursing pack must meet the following product standards.

| Standard | Required learner outcome |
| --- | --- |
| **Local-first access** | Learning opens without account creation or a network connection once local content is available. |
| **Structured topic map** | The pack contains an explicit, subject-specific set of reviewed topic units rather than only a few launch cards. |
| **Varied four-topic session** | A session selects distinct topics without repetition, balances new work and private revisit needs, and avoids consecutive activity modes when alternatives exist. |
| **Direct discovery** | Learners can search only within the active subject, open an exact topic, and revisit a saved item without crossing into another pack. |
| **Clear feedback** | Each activity explains the reasoning or next learning step. Writing/reflection remains private and is never presented as automatically graded work. |
| **Private progress** | Outcomes, saved topics, milestones, and study streaks remain on device, with no public comparison, grades, attendance claims, or prediction. |
| **Appropriate voice support** | Spoken prompts and optional reflections use the established device voice preference while respecting each subject’s content boundaries. |
| **Assessment readiness** | Timed sessions appear only when a pack has sufficient original content and are clearly framed as Rounds practice, not an official examination simulation. |
| **Original and safe content** | Each subject keeps its own examples, language, reasoning styles, and explicit safety boundaries. Nursing is the architecture reference, not a content template. |

## Step-by-Step Upgrade Sequence

1. **Shared model.** Extract a subject-neutral local topic-unit and adaptive-session foundation from the tested high-school architecture.
2. **University packs.** Upgrade University Foundation Year, Computing, Business, Engineering, Natural Sciences, Education, and Social Sciences using pack-specific topic maps and learning modes.
3. **High-school completion.** Connect all nineteen existing high-school packs to the shared parity surface, retaining their established local topic depth, level scope, milestones, streaks, search, and saved-topic safeguards.
4. **Voice and assessment.** Add non-clinical spoken prompts and only then add clearly labelled timed practice where content depth supports it.
5. **Verification.** Add tests for pack isolation, topic depth, varied no-repeat selection, local-only data boundaries, search, saved review, and subject-specific safety labels.

## Deliberate Non-Goals

The parity programme will not claim official NCDC/UNEB coverage, replace a university course, issue grades, provide professional guidance, reuse Nursing content outside Nursing, or make subjective written/creative work appear automatically graded. It will prioritize transparent original practice that students can use repeatedly on their own devices.
