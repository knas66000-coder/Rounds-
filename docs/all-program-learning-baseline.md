# Rounds All-Program Learning Baseline

## Decision

Every active Rounds program will use the same **learning architecture** as Nursing. Equal treatment means each pack supports a local learning round, non-repeating activity queue, answer or draft interaction, immediate educational feedback, save-for-review, session progress, a fresh-round control, and local continuation. It does **not** mean that every subject uses Nursing clinical prompts, identical grading, voice requirements, or the same number of currently reviewed items.

## Transferable Nursing Baseline

| Nursing capability | Shared baseline for every active pack | Subject-specific adaptation |
|---|---|---|
| Unique question queue | A no-repeat local activity round | Evidence, writing, logic, calculation, or scenario activities |
| Typed recovery | Every activity has an accessible typed route | Writing may be the primary response rather than a fallback |
| Immediate answer feedback | A clear result and explanation after completion | Evidence activities validate a choice; writing activities confirm a saved private plan rather than auto-grade it |
| Bookmark | Save an activity for later review | Same local bookmark behavior for all packs |
| Session snapshot | Completed, correct/ready-to-review, and saved counts | Writing tracks completion, not correctness |
| Fresh round | Start a new local order once the queue is complete | Same per-pack control |
| Adaptive/review direction | Saved or incomplete work is easy to revisit | It may not infer academic mastery from a private writing draft |
| Offline continuity | Installed content and progress work without data | Foundation Year adds an explicit local install; embedded starters are ready locally |

## Equivalence Rules

1. **Every active pack receives the same shell.** The program home opens a round; the course library exposes activity detail and review controls; progress remains private and local.
2. **Every round is no-repeat.** A learner sees each reviewed local activity once before choosing a fresh order.
3. **Every completed activity receives feedback.** Feedback explains why a choice is supported or what a saved draft has achieved; it does not invent a score for subjective work.
4. **Every activity can be saved.** Bookmarks use one shared local data contract and never cross from one subject into another.
5. **Every pack keeps its subject boundary.** Nursing clinical content stays within Nursing. Other packs use their own evidence, design, social, educational, scientific, business, or technical contexts.

## Current Content Boundary

The shared engine can be delivered now with original, limited starter activities. Content volume will expand only after subject review. Rounds will display an honest activity count and will not misrepresent starter material as a complete institutional course.
