# Security policy

Please do not publish security vulnerabilities, learner data, credentials, or reproduction details in public issues. Report a potential vulnerability privately to the repository owner with a concise description, affected screen or service, impact, and safe reproduction steps.

Do not include real learner records, patient information, session tokens, passwords, backup passphrases, database URLs, API keys, or unredacted screenshots in a report. The repository owner should acknowledge the report, assess impact, and coordinate a fix before public disclosure.
